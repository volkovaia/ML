## Ключевые технологии

### 1. Критика PCA и переход к селекции
Начальное сжатие через PCA (150–1500 компонент) приводило к потере сигнала. В разреженных данных информация скрыта в конкретных значениях редких признаков. Переход к **KS-test (Kolmogorov-Smirnov)** помог выявить признаки с дрифтом между train/test, но в итоге лучшим решением стал **отбор признаков по Gain Importance** (LightGBM).

### 2. "Магия" ненулевых статистик (NZ-Stats)
Улучшение на **~0.05** принес отказ от стандартных статистик в пользу расчёта только по активным ячейкам:
- `nz_median`, `nz_mean`, `nz_std`, `nz_skew` — расчёт только по значениям `!= 0`.

**Результат:** модель научилась эффективно различать масштаб транзакций клиента, игнорируя "нулевой шум".

### 3. Восстановление временных цепочек 
Ключевым открытием стало обнаружение того, что датасет — это фрагменты временных рядов.

- **Структура:** найдена упорядоченная группа из 40 колонок, в которых значения сдвинуты на одну позицию между соседними (по времени) строками.
- **Логика:** если для строк A и B выполняется условие `B[magic[1:]] == A[magic[:-1]]`, значит строка B является прямым продолжением строки A.
- **Реализация:** построен хэш-словарь для быстрого поиска "предков" строк. В случаях совпадения таргет брался напрямую из признаков следующей строки.

### 4. Pseudo-labeling: обучение на тесте
Был проведен эксперимент по добавлению предсказаний теста в обучающую выборку. Метод не дал прироста точности (score упал до 1.43), что подтвердило риск переобучения на собственных ошибках (label propagation error) при малом объеме достоверных данных (Train < 5000 строк).

## Финальный стек

### Preprocessing
- Очистка от констант
- Удаление дубликатов
- Двойная логарифмизация (`log1p`) признаков и таргета

### Features
- Топ‑1000 оригинальных признаков
- NZ‑агрегаты (**Median NZ** — самый важный признак)
- `TruncatedSVD` (20 компонент) для извлечения латентных связей

### Models
Ансамбль из двух моделей:
- **LightGBM** — находил сложные зависимости
- **RandomForest** — обеспечивал бэггинг‑стабильность на зашумленных данных

### Ensemble
- Взвешенный бленд в логарифмической шкале
- Пост‑обработка (**Rank Blending**)
